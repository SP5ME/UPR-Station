# Ustawienia UPR Station

Powiadomienia: centrum powiadomień, Telegram i dźwięk w przeglądarce.
WWW: logowanie, obecność operatora, statystyki, MQTT i aktualizacja Alpine. Brak zakładki autostartu desktopu.

Rozwijane sekcje są domyślnie zwinięte. Przełączanie zakładek ustawień nie
kasuje ich stanu, zapis i wyjście z ustawień zwijają sekcje.
Format starej konfiguracji i pliki sekretów pozostają zachowane.
