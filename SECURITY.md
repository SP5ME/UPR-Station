# Zgłaszanie podatności

Projekt jest w pre-alfa; nie deklarujemy gwarantowanego czasu reakcji ani
utrzymania starszych wydań. Nie wystawiaj panelu bezpośrednio do Internetu.
Stosuj uwierzytelnianie, ograniczenia sieciowe i zabezpieczone połączenie.

Nie publikuj podatności ani sekretów w publicznym issue. Po włączeniu prywatnych
zgłoszeń użyj Security → Report a vulnerability. Jeżeli ta funkcja nie jest
dostępna, poproś opiekuna o prywatny kanał bez ujawniania szczegółów podatności.

Podaj wersję, wariant, środowisko i minimalny opis odtworzenia. Zanonimizuj dane.
Nie dołączaj prawdziwych haseł, tokenów, kluczy ani cudzych wiadomości.
