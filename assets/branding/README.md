# UltimatePR — ikony rodziny i Station

Aktualny znak: **UPR_ — UPR Terminal**. Do WWW należy używać podstawowego
logo bez monitora. Ikona Windows zawiera monitor z białym ekranem.

## Aktualne pliki

- `ultimatepr-logo.png`: podstawowe logo UPR_ z przezroczystym tłem, do WWW.
  Kopia używana przy budowaniu znajduje się także w katalogu głównym projektu.
- `ultimatepr-station-icon.png`: ikona Station z białym ekranem.
- `ultimatepr-station-icon-256.png`: ikona Station 256 × 256.
- `ultimatepr-station-icon.ico`: ikona Windows, rozmiary 16, 24, 32, 48,
  64, 128 i 256 px.

Wygenerowano wbudowanym ImageGen z zaakceptowanej środkowej kolumny planszy
„02 / UPR TERMINAL”. Prompt logo: sam napis UPR_, grube proste litery
terminalowe ze ściętymi narożnikami, zieleń #426a46, przezroczyste tło,
bez podpisu i monitora. Prompt ikony: ten sam napis w zielonej ramce
monitora, biały ekran, oddzielna podstawa, przezroczyste otoczenie.
Eksport ICO przez System.Drawing. Są to pliki rastrowe, nie SVG.
